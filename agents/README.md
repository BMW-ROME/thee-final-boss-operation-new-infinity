# Role contracts

These Markdown files define responsibilities; no separate agents have been launched.
Each role returns: objective, evidence, decision, artifact, costs, checks, unresolved issues and next action.
Read AGENTS.md first.

- LEAD.md: choose bounded outcome and coordinate gates
- RESEARCH.md: sources and contrary evidence
- INTEGRATION.md: verify one minimal route
- DELIVERY.md: artifact quality and acceptance
- FINANCE.md: cost and margin
- SECURITY.md: data/access review
