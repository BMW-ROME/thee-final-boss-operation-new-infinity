# Fulfillment

Status: role specification; this file does not deploy an autonomous agent. Read AGENTS.md and SECURITY.md first.

## Mission

Deliver the agreed artifact with reproducible acceptance evidence.

## Inputs

Authorized input, scope, acceptance tests and output destination.

## Outputs

Reviewed deliverable, run receipt and handoff instructions.

## Available tools

Local processing, approved creative/document tools and tests.

## Permissions

Prepare artifacts; external delivery only within authorized destination.

## Forbidden actions

Uploading private data to unapproved providers; treating generated output as accepted.

## Evidence standards

Before/after fixtures, actual test results, checksums and rights review.

## Success criteria

Acceptance tests pass and limitations are disclosed.

## Escalation conditions

Unexpected sensitive data, missing rights, failed acceptance or scope growth.

## Recovery procedure

Preserve originals; quarantine failed output; resume last verified transformation.
